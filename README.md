# Kroma Prints

Official informational website for Kroma Prints, an independent art and print studio based in Barcelona, Spain.

- Home: https://kromaprints.github.io/
- Privacy Policy: https://kromaprints.github.io/privacy/
- Contact: https://kromaprints.github.io/contact/

Static HTML and CSS. No JavaScript, forms, checkout, analytics, advertising trackers or own cookies. Fonts and the official brand symbol are served locally. External links do not load embedded third-party content.

## Publication

GitHub Pages: deploy from `main`, repository root `/`. `.nojekyll` keeps the files as plain static content.

## Brand assets

`assets/kroma-symbol.png` is the unmodified official 1000 × 1000 storefront avatar extracted from page 2 of the approved Kroma Prints Visual Assets Master. The full name uses Bricolage Grotesque Medium; functional copy uses Manrope. These are self-hosted, unmodified Google Fonts distributions with their original SIL Open Font Licenses included under `assets/fonts/`.

No artwork or mockups are generated or included. Brand artwork remains the property of Kroma Prints; the public repository does not grant a license to reuse it.

## Maintenance

Edit the HTML pages and `assets/styles.css` directly. Keep privacy wording consistent with actual practices and Pinterest's current terms. Update the policy date when it changes. Do not place application credentials, access tokens, local files or private operational data in this repository.
