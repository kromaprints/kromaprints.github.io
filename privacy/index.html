Privacy Policy

Last updated: October 7, 2026

Kroma Prints is an independent art and print studio based in Barcelona, Spain. This Privacy Policy explains how information is handled in connection with the Kroma Prints website and the internal application Kroma Prints Automation.

1. Website

This website is provided for informational purposes and to provide access to Kroma Prints, its Etsy shop, and this Privacy Policy.

Kroma Prints does not intentionally collect personal information from visitors through this website. The site does not contain a customer account system, checkout, newsletter subscription or contact form. It does not use its own cookies, analytics or advertising trackers.

This website is hosted using GitHub Pages. GitHub may process technical information, such as IP addresses and request information, as part of providing its hosting services. Such processing is governed by GitHub’s own Privacy Statement.

Links to Etsy and Pinterest lead to external services governed by their own privacy policies. If you choose to contact Kroma Prints by email, the information you provide is used to respond to your enquiry and handle any follow-up.

2. Kroma Prints Automation

Kroma Prints Automation is an internal, single-user application intended exclusively for Kroma Prints to connect its own Pinterest Business account to the Pinterest API, subject to Pinterest approval and authorization.

The application is not offered to customers or third-party users.

When authorized, the application may access information made available through the Pinterest API for the authorized Kroma Prints account, including:

  • Pinterest account identifiers;
  • Boards and Board information;
  • Pins and Pin metadata;
  • Pin performance and analytics data;
  • authorization information required to maintain the authenticated Pinterest API connection.

3. Purpose of processing

Pinterest API information is used only to:

  • create and publish approved Pins;
  • schedule Pinterest content;
  • manage Kroma Prints Boards;
  • retrieve Pin-level performance analytics;
  • measure and improve the performance of Kroma Prints organic Pinterest content.

These activities are subject to the permissions and limitations of the access granted by Pinterest. Pinterest API information is not used to build advertising profiles for third parties.

4. Sharing and sale of information

Kroma Prints does not sell Pinterest API information.

Pinterest API information is not shared with third parties, except where required by law or expressly permitted by Pinterest’s applicable terms.

Data obtained from Pinterest is used only for the Kroma Prints account from which it originates.

5. Authentication and security

Pinterest authentication credentials and access tokens are treated as confidential and are used only to operate the authorized Kroma Prints integration.

Kroma Prints does not request or store Pinterest account passwords.

Reasonable technical and organizational measures are used to protect credentials and information used by the application from unauthorized access.

6. Data retention

Retention of Pinterest API information is limited to what Pinterest’s applicable Developer Guidelines and API terms expressly permit. Where retention is not permitted, information must be retrieved from the API when needed rather than stored persistently.

Information whose retention is permitted, including eligible analytics information and authorization records, may be retained only for as long as reasonably necessary for the authorized integration, permitted historical performance reporting or troubleshooting, subject to Pinterest’s requirements and applicable law.

Information that is no longer required for these purposes is deleted. Email correspondence is kept only for as long as necessary to handle the enquiry, its follow-up and any applicable legal obligations.

7. Your rights

Where applicable under data protection law, individuals may request access to, correction of, restriction of, or deletion of personal information processed by Kroma Prints. Applicable rights may also include objection to processing and data portability.

To make a request, contact kromaprintsbcn@gmail.com. Individuals may also lodge a complaint with the competent data protection authority, including the Spanish Data Protection Agency (AEPD).

Because Kroma Prints Automation is an internal application connected only to the Kroma Prints Pinterest Business account, it is not designed to collect Pinterest data belonging to external users.

8. Changes to this policy

This Privacy Policy may be updated from time to time to reflect changes to the website, Kroma Prints Automation, applicable law or the services used by Kroma Prints.
